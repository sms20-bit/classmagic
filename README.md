## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🎲 **룰렛 발표자 뽑기** | 학생 이름을 입력하면 룰렛이 돌아가며 발표자 선정, 폭죽 효과 |
| 👥 **모둠 구성기** | 학생 목록을 넣으면 랜덤으로 모둠을 자동 편성 |
| 📸 **화면 캡처** | 수업 중 화면을 즉시 캡처, PNG 저장 및 클립보드 복사 |
| ⏱️ **타이머 / 스톱워치** | 수업 시간 관리용 카운트다운 타이머와 스톱워치 |
| 🍅 **뽀모도로 타이머** | 집중 25분 / 휴식 5분 자동 전환, 사이클 카운터 |
| 📷 **QR코드 생성** | 링크나 텍스트를 QR코드로 즉시 변환, PNG 저장 |
| 📝 **수업 진도 메모** | 체크리스트 + 자유 메모, 자동 저장, 텍스트 내보내기 |
| 🎨 **화이트보드** | 펜·형광펜·도형·텍스트, 다크모드, PNG 저장 |
| 🖱️ **마우스 커서 변경** | 전자칠판용 대형 커서, 별·하트 등 12가지 모양 |
| 🔔 **알람 소리 선택** | 딩동댕·차임벨·알람·팡파레 4종 중 선택 |

## 🚀 설치 방법

### 1. 다운로드
- 우측 **Releases** 탭 → 최신 버전 `SuupMabeobsa.zip` 다운로드

### 2. 압축 해제
- 다운로드한 ZIP 파일 압축 해제
- 폴더 안에 `manifest.json`이 있는지 확인

### 3. 크롬에 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 토글 **ON**
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 압축 해제한 폴더 선택
5. 크롬 상단 🧩 아이콘 → 수업마법사 📌 고정
