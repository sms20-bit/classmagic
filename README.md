# 🏫 ClassApp Builder — 수업 보조 미니 앱 빌더

> 전자칠판·빔프로젝터 최적화 크롬 확장프로그램  
> 발표자 뽑기 · 모둠 구성 · 단어 카드 · 타이머 4가지 기능 올인원

---

## 📁 파일 구조

```
ClassAppBuilder/
├── manifest.json     ← 확장프로그램 선언 파일 (MV3)
├── popup.html        ← UI 구조
├── popup.css         ← 스타일 (파스텔 테마)
├── popup.js          ← 전체 로직
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

---

## ⚙️ 설치 방법 (크롬 기준)

1. 크롬 주소창에 `chrome://extensions` 입력 후 Enter
2. 우측 상단 **"개발자 모드"** 토글 **ON**
3. **"압축해제된 확장 프로그램 로드"** 클릭
4. 이 폴더(`ClassAppBuilder`) 전체를 선택
5. 브라우저 우측 상단 퍼즐 아이콘 → 📌 고정 클릭
6. 아이콘 클릭 시 팝업 실행 ✅

## 🎯 기능 요약

| 탭 | 기능 | 특수 효과 |
|---|---|---|
| 🎲 발표자 | 룰렛 랜덤 뽑기 | 폭죽(Confetti) + 딩동댕 알람 |
| 👥 모둠 | 무작위 조 편성 | 컬러 카드 시각화 |
| 🃏 단어카드 | 플래시 카드 학습 | 3D 뒤집기 효과 |
| ⏱️ 타이머 | 카운트다운 + 스톱워치 | 종료 알람 + 경고 깜빡임 |

---

## ⌨️ 단축키

| 키 | 동작 |
|---|---|
| `Space` | 발표자 탭에서 뽑기 실행 |
| `←` / `→` | 단어 카드 이전/다음 |

---

## 💾 데이터 자동 저장

- 학생 이름 목록, 단어장, 당첨 기록 → `chrome.storage.local` 자동 저장
- 브라우저 재시작 후에도 데이터 유지

---

## 🛠 커스터마이징 팁

- `popup.css`의 `:root` 변수에서 `--c-primary` 등 색상 변경 가능
- 알람 멜로디 음정: `popup.js` `AudioAlarm` 섹션의 `playNote(ctx, 주파수, ...)` 수정
- 팝업 크기: `popup.css` `html, body { width / height }` 조정
